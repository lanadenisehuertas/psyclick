P16 [Normal]: I. Project Overview
P17 [Normal]: The Final Project requires students to propose, design, and evaluate a secure information system that addresses a real-world organizational problem. The project must demonstrate the application of Information Assurance and Security principles, including confidentiality, integrity, availability, authentication, authorization, accountability, risk management, and cybersecurity controls.
P18 [Normal]: Students will produce a complete system proposal, security architecture, implementation prototype (if applicable), security assessment, and final defense presentation.
P19 [Normal]: 
P20 [Normal]: II. Project Objectives
P21 [Normal]: By the end of the project, students should be able to:
P22 [Normal]: Identify security requirements for an information system. 
P23 [Normal]: Conduct risk assessment and threat analysis. 
P24 [Normal]: Design secure system architecture. 
P25 [Normal]: Implement appropriate security controls. 
P26 [Normal]: Evaluate system vulnerabilities and mitigation strategies. 
P27 [Normal]: Apply information assurance principles in system development. 
P28 [Normal]: Present and defend security decisions professionally.
