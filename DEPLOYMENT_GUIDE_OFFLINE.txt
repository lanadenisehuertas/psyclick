───────────────────────────────────────────────────────────────────────────────
 DATA STORAGE (100% LOCAL)
───────────────────────────────────────────────────────────────────────────────

All data stored in local SQLite database ONLY:
  Location: C:\Users\[YourUsername]\AppData\Roaming\PsyClick\psyclick_data.db

The database is a standard SQLite file:
  • Can be opened with any SQLite tool (no special software needed)
  • Can be copied to USB drive for archival
  • Can be backed up to network drives (while PsyClick is closed)
  • Contains all patient sessions, assessments, and clinical results

Backup procedure:
  1. Exit PsyClick application completely
  2. Open File Explorer
  3. Navigate to: %APPDATA%\PsyClick\
  4. Copy file: psyclick_data.db
  5. Save to USB drive, backup drive, or encrypted cloud storage

Restore procedure:
  1. Exit PsyClick application
  2. Paste psyclick_data.db into: %APPDATA%\PsyClick\
  3. Overwrite existing file
  4. Restart PsyClick

───────────────────────────────────────────────────────────────────────────────
 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

ISSUE: "Database Error" on startup
  CAUSE: Corrupted psyclick_data.db file
  SOLUTION 1: Delete %APPDATA%\PsyClick\psyclick_data.db
  SOLUTION 2: Restore from backup
  SOLUTION 3: Reboot and try again

ISSUE: "Cannot write to database"
  CAUSE: File permissions or disk full
  SOLUTION 1: Check disk space
  SOLUTION 2: Check file permissions on %APPDATA%\PsyClick\
  SOLUTION 3: Move to partition with more space
  SOLUTION 4: Run as Administrator

ISSUE: Application won't start
  SOLUTION 1: Reboot computer
  SOLUTION 2: Reinstall application (Setup.exe)
  SOLUTION 3: Check log file: %APPDATA%\PsyClick\api_startup.log

ISSUE: "Cannot connect to database URL"
  CAUSE: (This should NOT appear in Offline Edition)
  SOLUTION: Delete any config.json files in:
    - %APPDATA%\PsyClick\
    - Installation directory
    - Restart application
