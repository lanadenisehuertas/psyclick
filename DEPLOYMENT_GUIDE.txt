✅ OFFLINE-READY SYSTEM (No internet required)

───────────────────────────────────────────────────────────────────────────────
 SYSTEM REQUIREMENTS
───────────────────────────────────────────────────────────────────────────────
- Windows 10/11 (64-bit)
- No internet required
- No cloud database required
- ~500MB disk space

───────────────────────────────────────────────────────────────────────────────
 INSTALLATION (One-time)
───────────────────────────────────────────────────────────────────────────────

1. CLINICAL EDITION (Clinician-only interface):
   • Double-click: PsyClick Clinical Edition Setup.exe
   • Follow wizard, choose installation directory
   • Creates: PsyClick Clinical Edition (Start Menu shortcut)
   • Database auto-created: %APPDATA%\PsyClick\psyclick_data.db (local SQLite)

2. STANDARD EDITION (Tester + Clinician dual-mode):
   • Double-click: PsyClick Setup.exe
   • Follow wizard, choose installation directory
   • Creates: PsyClick (Start Menu shortcut)
   • First launch: Choose Tester or Clinician mode
   • Database auto-created: %APPDATA%\PsyClick\psyclick_data.db (local SQLite)

───────────────────────────────────────────────────────────────────────────────
 LAUNCHING THE APPLICATION
───────────────────────────────────────────────────────────────────────────────

CLINICAL:
  - Start Menu → "PsyClick Clinical Edition"
  - OR: Double-click desktop shortcut "PsyClick Clinical Edition"
  - Launches clinician dashboard (view sessions, results, comparisons)

STANDARD (Dual-mode):
  - Start Menu → "PsyClick"
  - OR: Double-click desktop shortcut "PsyClick"
  - Launcher appears → Select:
    • TESTER: Run normative calibration sessions (for research)
    • CLINICIAN: Assess patient intake sessions (for clinical use)

───────────────────────────────────────────────────────────────────────────────
 FIRST-TIME SETUP
───────────────────────────────────────────────────────────────────────────────

TESTER MODE (Standard Edition):
  1. Click "Start Calibration"
  2. Type normally for 30 seconds (keyboard speed baseline)
  3. Click circles on screen (mouse dynamics baseline)
  4. Complete PHQ-9 (mental health screening)
  5. Complete GAD-7 (anxiety screening)
  6. Complete 3 emotional response questions (~3 min each)
  7. System calculates scores and saves locally

CLINICIAN MODE:
  1. Login as "clinician" (no password for demo)
  2. Dashboard shows: Patient list, recent sessions, flagged results
  3. Click a patient session to view detailed analysis
  4. See results breakdown:
     - T² Score (cognitive anomaly detection)
     - PSI (Psychomotor Slowing Index)
     - PAI (Psychomotor Agitation Index)
     - PHQ-9 / GAD-7 scores
     - Population comparison (percentiles vs 110 normative subjects)

───────────────────────────────────────────────────────────────────────────────
 DATA STORAGE (LOCAL ONLY)
───────────────────────────────────────────────────────────────────────────────

All data stored in local SQLite database:
  Location: C:\Users\[YourUsername]\AppData\Roaming\PsyClick\psyclick_data.db

Backup procedure:
  1. Exit PsyClick application
  2. Open File Explorer
  3. Navigate to: %APPDATA%\PsyClick\
  4. Copy file: psyclick_data.db
  5. Save to USB drive or cloud storage

Restore procedure:
  1. Exit PsyClick application
  2. Paste psyclick_data.db into: %APPDATA%\PsyClick\
  3. Overwrite existing file
  4. Restart PsyClick

───────────────────────────────────────────────────────────────────────────────
 DEMO WORKFLOW
───────────────────────────────────────────────────────────────────────────────

COMPLETE A FULL ASSESSMENT (10-15 minutes):

1. Open PsyClick Standard Edition → Select TESTER
2. Enter Student ID (e.g., "DEMO-001")
3. Complete all phases:
   - Keyboard Calibration (30s typing)
   - Mouse Calibration (click circles)
   - PHQ-9 Screening (9 questions)
   - GAD-7 Screening (7 questions)
   - Emotional Response Task (3 prompts, ~3 min each)
4. Wait for "Assessment Complete" message
5. Exit TESTER mode

6. Open PsyClick Clinical Edition OR switch to CLINICIAN mode
7. View "Clients" or "Dashboard"
8. Locate "DEMO-001" in recent sessions
9. Click session to see results:
   ✓ T² Score (anomaly detection, 0-20 scale)
   ✓ PSI (psychomotor slowing, 0-40 scale)
   ✓ PAI (psychomotor agitation, 0-108 scale)
   ✓ Percentile comparison vs population
   ✓ Flag status (GREEN/AMBER/RED)

───────────────────────────────────────────────────────────────────────────────
 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

ISSUE: Application won't start
  → Try: Reboot computer
  → Try: Reinstall application (Setup.exe)
  → Check: C:\Users\[User]\AppData\Roaming\PsyClick\api_startup.log

ISSUE: Database error or "Cannot create session"
  → Solution: Delete C:\Users\[User]\AppData\Roaming\PsyClick\psyclick_data.db
  → Then restart (fresh database will be created)

ISSUE: Results show 0.0 or missing values
  → Solution: Ensure entire assessment completed
  → Try: Complete assessment again with 20+ character responses

ISSUE: "Database unavailable" message
  → This system uses LOCAL database (no internet needed)
  → If error persists: Delete psyclick_data.db and restart
